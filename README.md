# 🏠 Sydney Property Sales Analysis | Excel

An Excel-based data analysis project using **54,986 Sydney property sales records from 2015–2018** to analyze property prices, sales volume, property types, bedrooms, suburbs, districts, and local government areas (LGAs).

The project demonstrates how Excel can be used to **prepare, enrich, analyze, and extract insights from a large real-world-style dataset**.

---

## 📊 Project Overview

**Dataset:** 54,986 property sales records
**Period:** 2015–2018
**Coverage:** 322 suburbs | 33 LGAs
**Property Types:** Houses & Units
**Tool:** Microsoft Excel

### Key Business Questions

* How did property prices change over the years?
* Which suburbs and districts had higher property prices?
* Which LGAs recorded the most sales activity?
* How does property type affect pricing and sales volume?
* What patterns can be identified by number of bedrooms?
* How did sales volume change over time?

## 🧹 Data Preparation

A separate **suburb reference table** was used to enrich the main sales dataset with district information.

The workflow included:

1. Reviewing the raw property sales data
2. Preparing and organizing the dataset
3. Using **VLOOKUP** to add district information
4. Converting data into structured Excel Tables
5. Sorting and filtering records
6. Creating analysis tables
7. Comparing prices, sales volume, locations, and property characteristics
8. Identifying trends and patterns
